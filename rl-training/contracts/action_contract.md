# 动作语义契约(action_contract)

> 唯一权威 = 灵智系统引擎契约 §3(随合作交付)。训练侧镜像。

## 语义

- 维度 = **J=29**,f32,取模型第一个输出;每拍 `action.len() == J` 校验。
- 语义 = joint_mapping 序**绝对关节目标(rad)**——每拍整向量下发;引擎不做增量、不做保持。
- 速度型行为由策略自身实现(参考 deform:`act = q + Δ`,权重在 q 块取单位阵 + 偏置 Δ,
  经被控对象反馈逐拍积分)。
- 软限位钳制:出线前逐通道钳入 `[limits.min+margin, limits.max−margin]`
  (`safety.soft_limit_margin_rad`,缺省 **0.05**;无声明限位通道不钳)。
- 标定中立位必须落在软限位内(装载校验;G1 样例 elbow −0.75 = 软域 [−1.45,−0.05] 中点)。

## 对训练的约束

| 项 | 约束 |
|---|---|
| 动作空间 | 训练环境动作空间 = 同语义绝对关节目标(或导出头内转换——本平台环境直接输出目标) |
| 参数化 | 网络 tanh 输出 a∈[−1,1]^J → `target = clip(neutral + a·action_scale, soft_lo, soft_hi)` |
| 范围 | 限位外动作无训练意义——环境端裁剪 + 导出端裁剪头双保险 |
| 平滑 | 加速度/jerk 惩罚**必选**(出线逐拍直驱电机无滤波;tri_03:20ms 采样 max_step<0.05rad) |
| 急停 | 安全路径直写不经策略出线——训练无需建模,但策略不得依赖"越限动作"(会被钳制) |
