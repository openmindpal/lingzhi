# ONNX 文件规格契约(onnx_io)

> 唯一权威 = 灵智系统引擎契约 §4(随合作交付)。训练侧镜像。

## 规格

| 项 | 规格 |
|---|---|
| 输入 | 恰 **1** 个,形状 `[1, obs_dim]`,f32(输入名不检查,按位置喂) |
| 输出 | 首个输出,形状 `[1, J]`,f32(输出名不检查) |
| 运行时 | ort(ONNX Runtime),intra_threads=2,派发时装载会话 |
| opset | 固定(本平台导出 = 17) |
| 参考生成器 | 灵智系统随交付提供的 tri-family 参考实现——单 Gemm `act = W·obs + b` |
| 禁止 | 多输入图 / 动态形状 / 依赖观测契约之外模态(图像特征不在观测内) |

## 禁特权信息(Sim2Real 第一杀手)

观测只能来自现实世界同款传感器(编码器/IMU/力矩/腕部六维)——仿真中的上帝视角状态
(物体真值位姿、理想动力学状态、特权标志)一旦进观测,真机无此输入即瞎。
§2(obs_layout.md)布局就是白名单,逐位对齐;export_onnx 审计拒绝多余模态。

## 循环网络的诚实边界

引擎 IO = 单输入/单输出——LSTM/GRU 的 hidden state 进出图(2 输入)**不满足**当前契约。
当前可部署形态 = MLP(或帧堆叠——但帧堆叠改变 obs_dim,同样不在合法宽度集内)。
`algos/recurrent.yaml` 供研究实验;**导出部署仅放行 MLP**,循环权重导出 = 拒绝并说明原因
(引擎 IO 演化后重开此门)。
