具身智能原理对齐人，而人是分层的：大脑听懂话，小脑管动作，脊髓管安全——大脑从不直接控制肌肉。

行业内都是在训练“任务”——端茶、炒菜、拧瓶……任务无限，训不完。

灵智的解法：学音标，不背句子——只训练几十个动作原语（走稳、到位、抓握、合拢），“倒水”不是新技能，是原语的组合：走过去→抓杯→倾斜→看液面→停。组合由云端大脑干（大语言模型最擅长的事），原语由端侧小脑执行，安全由本地反射兜底。



# 第一部分 灵智系统是什么

**一句话:具身智能系统——云端大脑听懂语言、拆解任务、调度身体;端侧引擎让动作丝滑、安全、断网不断;机器人由此从"遥控设备"变成"听懂话干活的员工"。**

## 1. 云端引擎(认知大脑)

角色 = **大脑**:语言理解、任务分解、技能调度、结果验收。

| 能力      | 说明                                       |
| ------- | ---------------------------------------- |
| 任务理解与分解 | 自然语言目标 → 技能词序列 + 参数(位置/力/速度)——语义知识承载     |
| 多技能调度   | 按本体包声明的词表派发 → 回执核验 → 失败重试/求助(ask_user)   |
| 现场感知    | 把机器人看到的周围情况(有什么东西/在哪/朝向/远近)持续记下来——决策有现场感 |
| 生命周期    | 挂起/续跑/checkpoint/迭代硬帽/预算管理               |
| 持续演进    | 模型路由(用途级:主循环 Think/深度反思/分解/语音/提取/摘要)     |

# 第二部分 三个开源平台(厂商自助全链)

| 平台               | 职责      | 厂商在里干什么                                                   | 自检方式                                  |
| ---------------- | ------- | --------------------------------------------------------- | ------------------------------------- |
| `rl-training/`   | **训练面** | 本体接入(14 厂商位+通用模板)→ RL 训练(PPO/SAC/BC)→ 导出 ONNX(契约对齐)→ 过验收门 | `python tests/run_all.py`(零 GPU 一条命令) |
| `simulation/`    | **验证面** | 全套件机械判据(冒烟/扫掠/长跑/故障/Sim2Sim/金轨迹)——先仿真全绿再上真机               | `docker compose run --rm verifier`    |
| `body-sdk/`(本套件) | **交付面** | 按规范打包本体包 → 校验 → 签名 → 交给灵智系统验收上线                           | `python tools/validate.py <包目录>`      |

三平台开源、自包含、互相引用路径已对齐;厂商从训练到出厂**全程不碰灵智内部目录**。

**技能库收敛口径**:新任务优先认知组合(零训练);新原语仅在"运动模式级"增量——四族各 5~15 原语即达运动完备集,任务无限由组合承接。

# 第二部分之二 神经通路与技能原语——模型对齐机器人控制 + 动作泛化的实现

### 1 对齐链 = "模型对齐机器人控制"的完整神经通路

**云端模型认知下达 → 声明式技能 → 可验证技能原语 → 词表/短语**——对齐链是一条
**注册 → 派发 → 回执** 的闭环:

| 环                | 职责                        | 保证                                 |
| ---------------- | ------------------------- | ---------------------------------- |
| 声明式技能(词表+策略行+绑定) | 认知的调用界面与焊接点               | 装载期交叉校验——词绑定的策略须存在且 family 匹配,焊错拒载 |
| 能力注册             | 词/工具/身体图式上行落库             | 认知函数列表里只有真实能力——未注册词幻觉不出            |
| 认知下达             | 词名+参数(schema 约束解码)/短语令牌序列 | 输出永远落在声明过的有限安全集内                   |
| 可验证技能原语执行        | goal 参数→稳态位形→原语机制出线       | 三信号机械判据(说到不算,残差算)                  |
| 回执闭环             | 机械事实回流落库                  | 认知下一步基于事实不基于假设                     |

加 **感知/记忆/安全/仲裁** 四器官 = 完整具身形态(大脑从不直控肌肉——对齐靠链,不靠约定)。

### 2 动作原语词全集(31 训练件 + 接口/机制词)

- **操作(15)**:到达 · 抓 · 捏(手内精细) · 倒 · 插/穿 · 按(力收敛) · 擦(恒力) · 双手协同 · 击打 · 拦截 · 用工具 · 搬重物 · 织物操作 · 触觉盲操作 · 人机物理交互
- **移动(11)**:站(平衡保持) · 走(多速度档) · 侧移 · 后退 · 奔跑 · 持物走 · 地形行走 · 跳跃/翻跟头 · 闪避 · 摔倒爬起 · 按名导航
- **表达+形态(4)**:挥手节律 · 任意姿态保持(弯腰/叉腰/比心=一行数据) · 形态转移 · 情感条件化表达(情绪力学质感)
- **战术(1)**:快脑 goal 微调
- **调用接口词族(7)**:oscillate 挥摆 / aim 指向伸展 / gaze 注视 / pose 姿态 / return 回归 / trace 画线 / manipulate 任务
- **感知驱动机制原语(4)**:视觉伺服跟踪 · 滑移重抓 · 避障接近 · 反应动作

训练侧承载 = rl-training 任务族谱(29 任务定义,契约门全绿,§5b 注册表);
词表侧承载 = 本体包 words.rows(语料随本体攒行——能力声明,非行为脚本)。
**每个原语 goal 参数化覆盖无限实例,组合=无限任务**。

### 3 动作泛化怎么实现——三层分工(训练只买第一层)

| 层           | 泛化什么                                 | 谁承担           | 训练?       |
| ----------- | ------------------------------------ | ------------- | --------- |
| **层1 力学泛化** | 每步"抓住-拉整-切透-到位"的力学,goal 参数全域覆盖(课程采样) | 策略权重(原语族)     | ✅ 唯一训练的层  |
| **层2 序列泛化** | 不同任务=不同步骤链(叠 T恤 vs 卷毛巾;切块 vs 切丝)     | LLM 分解组合(步骤链) | ❌ 零训练     |
| **层3 语义泛化** | "T恤怎么叠""葱花怎么切"的**方法知识**              | LLM 预训练常识     | ❌ 零训练(现成) |

### 4 实例走查

**叠不同衣服、多种叠法**(fabric 原语):同一织物力学,变的是认知给的**抓取点序列参数**——
叠 T恤(抓左袖→领口→右袖→对折)/叠裤子(裤腰→对折腿)/三折毛巾/卷毛巾(抓角→卷动轨迹)。
每步判据(形态匹配/不撕裂)三信号裁决;滑掉→该步 replan 重抓,不从头再来。

**切不同的菜、切法不同**(tool 原语):同一持刀力学,变的是**刀轨迹参数流**——
番茄切块(2cm 网格)/葱花(3mm 密集)/土豆片(等距薄片)/滚刀块(点位+旋转协调)。
每刀 press 力收敛阈=切透的**物理判定**(不是视觉"看起来切开了")。

**结论**:衣服千变万化、菜谱千变万化,变的是层2 序列与层3 语义(认知,零训练),
层1 力学一个不变——**换任务不换训练,这就是"有限原语×参数×编排=无限任务"的具象**。

## 5. 三个最深的分歧点

1. **智能来源**:回忆(VLA,数据铺任务空间)vs 预测(世界模型,想象代替试错)vs 组合(灵智,有限原语×参数×序列=指数空间)。人的证据:**人从不逐任务训练肌肉**——学音标,词汇靠拼。
2. **纠正放哪层**:VLA 纠正=重新推理(反应率=推理率);世界模型纠正=事前预演;灵智三层——手上的毫秒修、眼上的帧级修、脑里的秒级修。人的证据:**手碰烫的瞬间缩手是脊髓干的,不过大脑——反射必须独立于思考**。
3. **安全与自主**:不可逆物理世界里,安全越级/断网自治/长时续跑不是"智能"是**系统结构**——模型路线不给,灵智内置且实证。

## 7. 结论:终局是融合,承重结构=分层——人已经证明了

- **VLA** = 小脑直觉的候选零件(数据买丝滑泛化,买不来安全/自主/分解深度)
