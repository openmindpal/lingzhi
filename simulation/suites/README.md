

# 灵智系统仿真验收套件（suites/）

> 被验系统 = 灵智系统——断言对象为灵智系统全链行为。
> 验证的可复现内核：每个套件 = 确定性输入 + 机械断言 + 报告产出。



| 目录 | 断言 | 章节 |
|---|---|---|
| sweeps/ | 目标位置/距离/物体/质量/摩擦扫掠 × 到位精度/成功率；域随机化表 = 本目录 domain_randomization.yaml（单一权威，training/ 引用） | §3.2 / §4.2 |
| longevity/ | 时间加速长跑：觉醒触发 / checkpoint 续跑 / 预算续做 / 挂起续跑 / TTL / 内存句柄泄漏曲线 | §3.3 |

## 运行口径

```
单套件：python -m suites.<目录>.run --package <包名>
全套：  python -m runner.run_all --suite all   ← 报告统一落 reports/
```

失败判据一律机械（数值阈值/状态断言），无"看起来对"通道——报告如实落失败项。
