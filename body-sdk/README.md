# body-sdk——灵智系统本体包对接套件(交付面)

> 厂商交付的最后一环:按规范打包 → 校验 → 签名 → 交给灵智系统验收上线。
> 前两环:训练 = `rl-training/`(策略),验证 = `simulation/`(仿真套件)——本套件只管**交付面**。

## 你有什么 / 交付什么 / 流程

```
① 填 body-package.toml        ← spec/本体包规范.md 逐段
② 预检   python tools/validate.py <包目录> --dev
③ 放权重 policies/*.onnx      ← rl-training 平台训练导出(契约对齐)
④ 签名   python tools/sign_package.py <包目录> <私钥PEM>
         (--generate 先生成密钥对;公钥 sec1 base64 交付灵智系统登记)
⑤ 严格校验 python tools/validate.py <包目录>        ← 全绿 = 交付
⑥ 灵智系统侧 tri 在环验收全绿 → 认证上线(认知层按 词+参数 派发)
```

## 三个平台各司其职

| 平台 | 职责 | 厂商动作 |
|---|---|---|
| `simulation/` | 验证 | 跑全套件看判据 |
| `rl-training/` | 训练 | 接入本体、训策略、过验收门 |
| `body-sdk/`(本套件) | 交付 | 按规范打包、签名、校验、出厂 |

闭源边界:灵智系统引擎(端侧 Rust 引擎 + 云端认知)不在本套件范围——以二进制镜像/SaaS 形态接入;
本套件交付的本体包 = 引擎装载的**唯一输入形态**(契约驱动,装上即认新本体)。
